# Internship Project - Flutter App with Firebase Phone Verification and JSON Server

This project is an internship assignment where I developed a Flutter application with Firebase phone number authentication and integrated it with a local JSON server to store user data (name, phone number). The user data is saved in a `db.json` file running on a local server (localhost).

## Features

- **Firebase Phone Authentication**: 
  - Users can register and log in using their phone numbers.
  - OTP (One-Time Password) is sent to the user's phone for verification.

- **User Data Storage**: 
  - After successful phone number verification, user details (name, phone number) are saved in a local JSON server (running on localhost).

- **User Interface**:
  - Simple and user-friendly interface built using Flutter.
  - Smooth navigation and clear onboarding process.

## Technologies Used

- **Flutter**: For building the cross-platform mobile application.
- **Dart**: The programming language used to develop the app.
- **Firebase Authentication**: For handling phone number verification and user authentication.
- **JSON Server**: A simple mock backend server running locally to simulate a real backend.
